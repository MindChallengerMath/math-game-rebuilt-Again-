This is a game where you solves mathematical problems 
until you fail one problem.
For now the only problems the player will find are simple equations: X (+, -, *, or /) Y 

I am planning on adding square roots and exponents in the future as I want to keep it simple for now in order to get the project out

You can follow the progress and lessons learned from this project and future projects at https://logicalcircle.substack.com/

Feel free to use this code to make your own game.
